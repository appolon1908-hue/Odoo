# Security evidence

The negative-authorization matrix is mandatory test scope. Source validation confirms that the scenarios stay enumerated and that mission modules do not add direct network writers, unrestricted elevation, raw SQL, public controllers, install hooks, embedded secrets, or enabled live capabilities.

A source test is not runtime proof. Exact-role Odoo record-rule tests, Keycloak service-account tests, Kong policy tests, and mTLS tests remain required in isolated staging.
