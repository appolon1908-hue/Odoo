# Configuration

Assign Lead Import Administrator, Lead Importer, Lead Reviewer, Compliance
Manager, and Middleware Service deliberately. Give every human/service account
only its permitted companies and call-center business units.

Configure upload size (default 100 MB), rows (100,000), preview limit (10,000),
chunk size (2,000), MIME allowlist, retention, retry count and delay. Create
campaign-scoped column mappings. Configure suppression, consent, campaign
calling hours and campaign activation in the existing call-center models.

Middleware URL and authentication reference are metadata only; plaintext
credentials are forbidden. Middleware publication, VICIdial delivery, n8n,
WhatsApp, email, SMS and emergency import default false.
