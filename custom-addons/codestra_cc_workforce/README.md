# Codestra Contact Center Workforce

Company-scoped agent shifts linked to Odoo Employees, resource calendars, optional telephony identities, and verified attendance records. The module calculates planned hours, observed overlap, and schedule adherence from typed timestamps.

Publishing a shift does not change VICIdial state, payroll, or provider systems. Payroll must never be derived solely from telephony events, and open attendance records are not treated as final evidence.
